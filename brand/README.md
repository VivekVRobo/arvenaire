# Arvenaire Brand Source

This directory contains the source-of-truth vector identity used by the Arvenaire website.

## Production structure

- `brand/source/` — master vector source files. Do not edit geometry casually.
- `assets/brand/` — optimized runtime copies referenced by the website.
- `assets/icons/` — browser/PWA identity assets.
- `css/brand.css` — website presentation rules for the approved identity.
- `js/brand-runtime.js` — applies the approved symbol + wordmark to legacy static navigation and preloader elements.
- `site.webmanifest` — installable-web-app identity metadata.

## Approved geometry

The four-path convergence symbol is the locked Arvenaire v1.0 master geometry. Colour variants may change by context; geometry must not.

Core palette:

- Midnight navy `#0B2444`
- Mineral ivory `#F6F3EC`
- Sapphire `#5F86B8`
- Deep sapphire `#294C73`
- Near black `#05070A`

The premium platinum/sapphire 3D render is a presentation expression. The flat SVG remains the production master.
