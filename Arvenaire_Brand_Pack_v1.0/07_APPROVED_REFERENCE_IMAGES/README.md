# Approved Reference Images

These files are the visual references for Arvenaire Brand Pack v1.0.

- The premium 3D logo is the approved presentation master.
- The flat navy-on-ivory image is the approved source reference used to reconstruct the vector master.
- App icons and banner assets in this folder are approved outputs from this pack.
- Identity boards record the intended visual system.

Do not silently replace these files with regenerated approximations. If a master changes, increment the brand-pack version and update `REFERENCE_MANIFEST.json`.
