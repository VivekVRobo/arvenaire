# Free PDF source files — release paused

This folder preserves the source copies of Arvenaire's free PDF guides. The guides are currently withheld from the resource catalog while claims, source dates, branding, accessibility, and page layouts are reviewed. The PDFs are excluded from future Vercel deployment uploads by the repository-root `.vercelignore`; the current live deployment changes only after an authorized deployment.

## Paid product is separate

The paid **Germany Automation & Robotics Transition Kit (2026)** is intentionally not stored in this public repository. Customer delivery should happen through the configured checkout/digital-product platform or other private storage after purchase.

- Do not commit paid ZIP bundles, editable customer assets, or private delivery links here.
- Keep private customer assets outside this repository.
- Build and verify the paid kit locally, then upload that bundle directly to approved private delivery storage.
- If a paid asset is accidentally committed, remove it from the current branch immediately and rotate/change any private delivery URL if one was exposed.

## Relisting acceptance rule

A PDF returns to the public catalog only after a named owner has checked the claims against dated primary sources, matched the title and description to the actual file, confirmed Arvenaire branding and contact/correction details, reviewed accessibility, rendered and visually inspected every page, and received CMO acceptance. Changing scholarship, employment, visa, or financial facts must be rechecked immediately before publication.
