# ARVENAIRE Brand Pack v1.0

This package is the production identity set for Arvenaire.

## Primary assets
- `01_MASTER_LOGO/Vector/arvenaire-master-symbol-navy.svg` — primary flat master geometry.
- `01_MASTER_LOGO/Premium_Render/arvenaire-master-premium-dark.png` — approved premium 3D presentation master.
- `02_WORDMARK/arvenaire-wordmark-web.svg` — web-safe wordmark.
- `03_FAVICON_APP_ICONS/` — favicon and app icon family.
- `04_BANNERS/` — branded header and hero assets.
- `06_WEB_READY/` — deployment subset.

## Identity idea
Arvenaire's symbol is a convergence/pathway mark. Multiple routes resolve upward into a clear direction while the negative space quietly suggests an `A`.

## Production rule
The flat vector symbol is the identity master. The metallic 3D artwork is a presentation expression, not a replacement for the master geometry.

See `08_QA/QA_REPORT.md` for verification results.
