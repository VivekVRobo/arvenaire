# Web Integration

Use these assets directly in the Arvenaire site.

## Recommended
- Navigation / light UI: `assets/arvenaire-symbol.svg`
- Browser icon: `assets/favicon.svg` + `assets/favicon.ico`
- PWA icons: `assets/favicon-192.png`, `assets/favicon-512.png`
- Branded cinematic header: `assets/arvenaire-hero.jpg`
- Color / typography variables: `brand-tokens.css`

## Important
The SVG is the geometry master for web identity. Do not rasterize the premium 3D logo and use it as a small navigation icon.

No font binaries are included in this package. Load Inter from your chosen licensed/web source or use the fallback stack in `brand-tokens.css`.
